# THE AI RISHI — final experience

What this branch actually ships.

## Product thesis

THE AI RISHI is a learning environment. The programme is FORGE-120. The visible brand is the name only. There is no slogan. The mark is the original eight-petal logo.

The page is one paper field. Home is a plate: the phase name, a construction drawn from that phase’s real summary and day range, and the days themselves. It is not a headline with a row of boxes under it.

## Plates

Every plate shares crop marks and, except Foundations, a ruler of the real day numbers. Published days are ink. The day under the pointer or keyboard is brass. The construction above the ruler is different for each phase, and its words come from that phase’s summary:

| Phase | Construction |
|---|---|
| Foundations | A staff. Each day is a rule. Longer rules are later days. Open days are brass. |
| Azure networking and identity | An outer boundary, a gap marked from the summary, a private region that does not touch the edge, an identity mark. |
| CI and delivery | One path. Summary words are the stations. A seal travels the path when motion is allowed. |
| Terraform and application | Strata labelled from the summary, cut by a state line. |
| Kubernetes | Three nodes, a link between them, workloads that change node. |
| AKS | A managed band. Summary words hang off it on leaders. |
| Infrastructure delivery | Forward stations and a return path. |
| Reliability | An SLI against a threshold, with one breach marked page. |
| RAG and controlled tool use | Passage rules. One is cited. Pointer chooses which. |
| Design and defence | A closed frame. The four evidence classes are OPERATED, GENERATED, SIMULATED, BLOCKED. |

Below the field, the 120 days are one measured span. A phase’s width is its day count, not an equal slice. Selecting it lists that phase’s real titles.

The instruments for days 89–105 are on the same paper. Reliability days draw a gate, a retry, an SLI, an alert, a tabletop, a record, or a boundary. Retrieval, policy, injection, and evaluation stay labelled teaching fixtures. There is no live model.

## Routes

| Route | What you do |
|---|---|
| Home | The plate fills the screen. Laptop: the measure, or scroll. Phone: previous/next, a plate, then day rows. |
| Learn | Day tiles by phase. Phone: one phase per screen. |
| Lesson | Paper reading room. |
| Guides | Poster, then a reading column with a progress rule. |
| Labs | Poster index. A lab’s recorded technologies are stations. |
| About | One chapter per configured section. |
| Search | Full-screen command layer. Grouped results. Arrow keys. Enter opens. |
| 404 / loading | Same paper field. Factual copy. |

Phone navigation is every enabled main item. The desktop bar keeps the configured primary/explore split.

## What was removed

The desk, the constellation, the pointer halo, the footer seed, the unused hero and section renderer, and `universe.css`. Padded research dumps are gone. The three docs in this set describe the plates that ship.

## Configuration

Homepage sections, navigation, and disabled channels still come from `platform.json`. YouTube and Instagram stay off until real items exist.

## Research synthesis

Not a site catalogue. What this pass kept:

| Kind | Taken | Rejected |
|---|---|---|
| Measured drawings | Crop marks, a day ruler, labels from the phase summary | Equal boxes, decorative diagrams |
| Unequal time | Phase width follows the day count | Ten identical nodes |
| Instruments | A fixture you can step through, labelled as a fixture | A fake model or a live counter |
| Phone | Prev/next, a plate, day titles, every nav item | A shrunk desktop |

## Accessibility and performance

The canvas is `aria-hidden`. The phase name, summary, and day list are text. Phase choice does not write history. Reduced motion draws once and does not travel the seal. The loop stops when the tab is hidden. One canvas, no WebGL.

## Deliberately avoided

Slogan. A second logo. Glass. Neon. Particles. Sci-fi labels. Fake media. Fake learner counts. Padded research files.
