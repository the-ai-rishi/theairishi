# THE AI RISHI experience v3

The product is FORGE-120. The picture has to teach that path. A WebGL object that does not change when the curriculum changes is decoration.

## What the visitor should understand

Systems, then cloud, delivery, a cluster, reliability, retrieval, a control boundary, then architecture defence.

AI is not the opening. Day 12 includes an LLM sampler. Day 59 is a read-only helper. Days 97–105 are where retrieval, policy, evaluation, injection, and a kill switch are the subject. Day 105 is infrastructure awareness. The site says that in HTML, not only in a canvas.

## Scroll states

The homepage instrument uses seven states, compressed from the ten stages:

| State | Curriculum it stands for |
|---|---|
| Seed | Before the path is named. The geometry is still small. |
| Foundations | Days 1–12 |
| Cloud | Azure networking and identity |
| Delivery | CI, Terraform, and the application container |
| Cluster | Kubernetes and AKS |
| Retrieval | Days 97–105. A closing ring stands for the policy boundary. |
| Defence | Days 106–120 |

The header readout uses these names. Completed lesson progress still lights the same core. Anonymous visitors stay at mastery 0. Nothing on the page pretends to be live traffic, live tokens, or a live model.

## What is HTML on purpose

The constellation is the 120-day map: ten stages, real titles, real progress dots.

The control section is the part that has to be understandable on a phone:

- documents → chunks → retrieval → context → citation → answer
- request → model → policy → validation → tool → result → evaluation → audit
- an injection fixture: ordinary question versus a hidden instruction
- a golden-eval fixture that fails because the citation is missing
- an MCP boundary with one allowed tool and one blocked tool
- the nine capability gates, with the evidence the roadmap actually names

Canvas does not hold those sentences. Reduced motion still shows the diagrams. Buttons are real buttons.

## What this version refuses

- A second “AI course” and a second “agents course” sitting after FORGE-120 as if days 97–105 were not already the control layer.
- Purple fog, a brain, or a robot as the explanation of RAG.
- Fake dashboards for latency, cost, or learners online.
- Copying every private lab onto the public lesson pages. Published lessons match the new day. Unpublished days stay titles until a lesson exists.
- GSAP, Lenis, or a page-transition library. The new information is the curriculum. The frame loop already moves the camera.
