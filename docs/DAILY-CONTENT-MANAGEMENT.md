# Daily content management

Today this site publishes AI and DevOps lessons, one guide, and one project. YouTube and Instagram JSON files are empty arrays and both channels are coming-soon.

A normal day:

1. Edit or add markdown under content/lessons, content/courses, content/guides, or content/projects.
2. If you added a path, also edit content/config/courses.json.
3. Run the validate script from package.json.
4. Open the local Next.js server and hit the route plus search.
5. Do not enable YouTube or Instagram until a real item exists.

See COMMON-TASKS.md and OPERATIONS/PRE-PUBLISH-CHECKLIST.md.
