# Start here

This repository is the website for **The AI Rishi**. It is a small, honest learning site.

On disk today: 15 AI/LLM lessons, 2 DevOps lessons, 1 guide, 1 project. There is no Python content. YouTube and Instagram lists are empty. Cloud, Interview, Updates, Career stay in config as planned or coming-soon. They are hidden until they have real public content.

## How config becomes the website
The homepage is a list of section instances in JSON. Each instance has a type. Code renders types. JSON chooses which instances are enabled.

## Folders
Edit: docs/, content/config/, content/lessons/, content/courses/, content/guides/, content/projects/, content/media/, public/brand/.
Developer-only unless adding a new section TYPE: app/, components/, lib/, scripts/.

## No code vs needs a developer
No code: new topic, rename, hide, remove; new lesson/guide/project; enable or disable a homepage instance; change copy, logos, favicon; enable a channel after it has items.
Needs a developer: a new homepage section TYPE (not hero, topic-grid, course-list, content-list, channel-grid, continue-learning, or cta). New visibility rules.

## Honest rule
An active topic with zero published content is not a populated homepage card. Keep empty areas planned or coming-soon with homepage and nav off.
