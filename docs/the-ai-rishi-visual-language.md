# Visual language

Date: 2026-10-02.

The homepage is one elevation of FORGE-120, not a landing page with an object beside it. Scroll changes which phase is drawn. The words stay the brand, the programme, and the phase name.

Ancient influence is order, proportion, and restraint. There is no lotus, temple, or costume. Modern intelligence is the curriculum’s own structures: a module, a cluster, a signal, a citation, a boundary. There is no brain, robot, particle field, purple wash, or glowing network.

## Geometry

Three strokes, used the same way everywhere:

| Stroke | Means |
|---|---|
| Cream line or rectangle | Structure: column, module, node, document, record |
| Gold line | A path: relationship, delivery, promotion, a selected chunk |
| Signal line (`#67e8f9`) | A measured signal, a citation return, or a closed boundary |

A node is a rectangle, not a glowing sphere. A path is a line with a direction. A boundary is a closed rectangle. Nothing in the drawing is a count of users, requests, or latency.

The shared baseline has ten ticks, one per phase. A gold measure grows with scroll. That line is position in the 120 days, not a score.

## What each phase draws

| Phase | Drawing |
|---|---|
| Foundations | One column, one small square, one long beam. Sparse on purpose |
| Azure networking and identity | Two posts and the line between them. The square sits on identity |
| CI and delivery | Three stations: source, CI, artifact |
| Terraform and application | A module rectangle. A path runs through it |
| Kubernetes | Cluster, node, two workloads, a line to the second node |
| AKS | The cluster on a platform bar, with identity outside it |
| Infrastructure delivery | Two modules. Promotion forward, rollback back |
| Reliability | A threshold. The signal crosses it |
| RAG and controlled tool use | Three documents, one chunk selected, a path into context, a citation back |
| Design and defence | One closed frame holding the column, the cluster, the signal, and a document |

Reduced motion uses the same drawing. It does not fall back to a different symbol. WebGL is not used for this elevation. The previous lotus, rings, and particle field were removed because they did not mean a phase.

## Typography

| Role | Treatment |
|---|---|
| Brand | Mono, tracked, `THE AI RISHI` |
| Tagline | Mono, the official line, not uppercased by CSS |
| Programme | Serif, the `h1`, `FORGE-120` |
| Phase | Mono, upper area: number, name, day range |
| Body | The programme sentence from `copy.heroDescription` |
| Metadata | Duration, phase count, day count |
| Day titles | Serif or plain text inside the control section, not a second hero |

## Motion

Scroll moves the phase index. The active drawing replaces the previous one. The measure line advances. Pointer position shifts the drawing a few pixels on a fine pointer. It does not rotate the scene, burst particles, or blur the type.

There is no boot veil. The first frame is the Foundations drawing plus the title block.

## Interaction below the elevation

The 120-day map is the catalogue: real titles, real phase, real local completion. Unpublished days stay planned titles.

Days 89–96 are a control, not a dashboard. Selecting a day changes a small figure and shows that day’s goal from the snapshot.

Days 97–105 are HTML:

- Three fixed chunks. One answers, one does not, one is an instruction hidden in content and is blocked. No similarity score.
- A review-only loop. A shell is blocked. A read-only function is allowed.
- Injection: trusted instruction beside untrusted content. The verdict changes.
- Golden eval: the expectation stays. The output can miss the citation or include it. Pass and fail look different.
- MCP: model, boundary, allowed tool, blocked tool, resource.
- Nine capability gates, with their evidence lines.

Each of those is labelled a teaching fixture when it is not the roadmap text itself.

## Colour, mobile, performance

Ink `#08080b`, cream `#f3eee4`, gold `#d4b46a`, signal `#67e8f9`. Circuit purple is not a wash on sections.

The elevation stacks: phase label, drawing, title block. Controls wrap. The header phase name ellipsizes so a long phase does not break the bar. The drawing is one SVG, so there is no WebGL startup cost on the homepage.

Canvas is not required to read the page. Headings, the programme sentence, the day map, and the control section are HTML.

## Rejected

Lotus and petal marks. Orbit rings. Generic particles. A sphere graph. Purple blobs. Neural wallpaper. A sci-fi HUD. An AI brain or robot. Cyberpunk chrome. Repeated circles as decoration. Fake live counters. A mastery percentage ring. Boot copy that is not the brand or the phase. “Rishi” prefixed onto subsystems. Alternate taglines.
