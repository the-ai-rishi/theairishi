# Authoring Guidelines

Please refer to the [CONTENT_GUIDE.md](CONTENT_GUIDE.md) and [PLATFORM_MANUAL.md](PLATFORM_MANUAL.md) for detailed instructions on how to author content, manage topics, courses, navigation, and site layout.

The site is fully configuration-driven via:
- `content/config/platform.json`
- `content/config/courses.json`

Add markdown files with appropriate frontmatter (including `topic` and `status`) to create new lessons, guides, and updates.
